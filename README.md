# Simulation of Two body interaction
This project is a physics-based simulation of a satellite orbiting Earth using basic gravity laws.
Concept:
The idea is to simulate a spacecraft moving under gravity in space.
Mainly to demonstrate a satellite-like object following physics equations.
The gravitational force between two bodies is given by: F=Gm1m2/r**2
Two bodies are defined: Earth and the spacecraft. The gravitational force is computed for each time step, and the force is converted into acceleration and velocity, and the position is updated. The positions are stored for trajectory plotting. Distance data is analyzed to compute orbital parameters. The output is a 2D graph of the trajectory of a satellite-like object under gravity.
Numpy and Matplotlib libraries are used to calculate the orbital trajectory, position, velocity, acceleration, distance, periapsis, apoapsis, and approx. orbital period.
